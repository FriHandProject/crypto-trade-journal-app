# Crypto Trade Journal App Flow Document

## Onboarding and Sign-In/Sign-Up
A new user arrives at the Crypto Trade Journal app by visiting the landing page, which presents a brief introduction to the journal features and invites the user to either sign up or sign in. To create an account, the user clicks the Sign Up button and is presented with a form requesting name, email address, and a secure password. Alternatively, the user may choose to sign up with a social login option, such as Google or GitHub, in which case they are redirected to the provider’s authentication page and then returned to the app with an active session. Once the sign-up form is submitted, the app sends a verification email. The user confirms their email by clicking the link in the message and is automatically logged in on return to the app. For users who already have an account, the Sign In button leads to a form for entering email and password or using a social login. If the user forgets their password, they select the Forgot Password link, supply their email address on the recovery page, and receive a reset link by email. Clicking the reset link brings them to a secure page where they choose a new password, after which they are redirected to the Sign In page. A logged-in user can sign out at any time by opening the profile menu in the top navigation bar and selecting Sign Out, which ends the session and returns them to the landing page.

## Main Dashboard or Home Page
Upon successful login, the user lands on the Dashboard, which is the central hub for all journal activities. The top navigation bar displays the app logo on the left, followed by links to Dashboard, Add Trade, Analytics, and Settings. On larger screens, a collapsible sidebar on the left lists the same navigation options along with a user avatar that opens the profile menu. The main content area is divided into two sections: the top region features key statistics such as total trades, cumulative profit/loss, and win/loss ratio in card widgets, while the lower region presents a table listing recent trade entries with columns for date, trading pair, entry price, exit price, P/L, and a thumbnail of the trade screenshot. A prominent Add Trade button sits above the table and opens the trade entry form. Users can access the Analytics page by clicking its navigation link to view detailed performance charts. All navigation items allow smooth transitions so that users never lose context when moving between pages.

## Detailed Feature Flows and Page Transitions

### Add Trade Flow
When the user clicks the Add Trade button on the Dashboard, a modal dialog appears containing the trade entry form. The form fields include date selector, trading pair dropdown, entry price input, exit price input, P/L display (auto-calculated), and a file input for the screenshot. After the user fills in the details and selects an image file, clicking Submit triggers the screenshot upload process. A loading indicator appears on the button while the file is sent to the upload API endpoint.

### Screenshot Upload Flow
The form first sends the image file to the /api/upload endpoint. During the upload, a progress bar is shown inside the modal. If the upload succeeds, the endpoint returns a secure URL for the stored image. This URL is then embedded into the trade data payload. If the upload fails due to network issues or file size limits, the user sees an inline error message in the form and can retry selecting or uploading the image.

### Trade Creation Flow
Once the screenshot returns a valid URL, the form automatically sends all trade details including the image URL to the /api/trades endpoint. The server validates the data, ensures the user is authenticated, and writes a new record in the database. Upon success, the modal closes and the Dashboard table refreshes to include the new entry. The top statistic cards also update to reflect the revised totals.

### Performance Analytics Flow
By clicking the Analytics link in the navigation bar, the user moves to the Analytics page. This view fetches all trade records via a GET request to the /api/trades endpoint and runs in-memory calculations to derive trends over time. The page displays interactive charts such as a line graph of cumulative P/L and a bar chart of wins versus losses. Hovering over data points reveals tooltips with exact values. A back button in the header returns the user to the main Dashboard.

### OCR Auto-Fill Flow (Advanced)
In the trade entry form, the user may choose to enable automatic data extraction from the uploaded screenshot. By toggling the Auto-Fill option before uploading, the app sends the image URL to a special OCR API endpoint. This service returns parsed values for trading pair, entry price, exit price, and date. The form fields are populated with the extracted data, allowing the user to confirm or edit them before final submission. If the OCR service cannot interpret the image, the form displays a message encouraging manual entry.

### Profile Editing Flow
The user accesses profile settings by opening the profile menu in the top navigation bar and selecting My Profile. The Profile page shows fields for name and email along with a Change Password section. Editing any personal information requires entering the current password for verification. Upon saving changes, the app displays a success notification and retains the user on the Profile page or allows them to return to the Dashboard via the navigation.

### Premium Subscription Flow (Optional)
Users can upgrade to a premium plan by clicking Upgrade in the sidebar. This navigates to a Payments page where they select a subscription tier, enter credit card details via an embedded payment form, and confirm purchase. On successful subscription, the user is redirected to the Dashboard and premium features such as additional analytics widgets become active. The user may manage their subscription from the Billing section under Settings.

## Settings and Account Management
The Settings page combines account preferences, notification controls, and billing management. Users arrive here by selecting Settings in the top navigation or sidebar. The page is organized into three tabs: Account, Notifications, and Billing. In the Account tab, users update personal details or change their password. In Notifications, they toggle email or in-app alerts for new trades, monthly summaries, or price alerts. The Billing tab shows current plan status, next payment date, and offers a button to cancel or upgrade the subscription. Each section has a Save Changes button that provides confirmation feedback. A breadcrumb at the top of the Settings page lets the user return to the Dashboard or Analytics without losing context.

## Error States and Alternate Paths
When the user provides invalid input, such as a nonnumeric price or an unsupported file type, the form displays inline error messages next to the relevant fields and disables the Submit button until corrections are made. If the network connection is lost during an API request, a toast notification appears at the bottom of the screen informing the user of the connectivity issue and offering a Retry button. In the case of an expired session detected by a 401 response, the app redirects the user to the Sign In page with a message indicating they must log in again. Should the server encounter an unexpected error, a fallback error page appears with a friendly apology and a button to return to the Dashboard or to contact support.

## Conclusion and Overall App Journey
From first visiting the landing page to recording the hundredth trade, the user’s journey is fluid and intuitive. A seamless sign-up process leads directly into a secure Dashboard where trades are logged, screenshots are uploaded, and real-time analytics reveal performance patterns. Advanced users benefit from OCR auto-fill and premium analytics, while everyone can manage their profile and subscription with confidence. Error handling ensures that mistakes and downtimes are handled gracefully, guiding the user back on track. Ultimately, the Crypto Trade Journal app empowers users to maintain a private, detailed record of their trading activity and to derive insights that inform smarter decisions over time.
